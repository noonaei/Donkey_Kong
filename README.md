# Donkey_Kong
Based on a group project originally developed with a team. 
This version is for personal portfolio purposes.

This is a command-line implementation of the classic Donkey Kong game. 
Play as Mario and climb through multiple levels filled with ladders, barrels, and ghosts to rescue Pauline from Donkey Kong.

* The game supports multiple board files, each representing a different level.

* Players can choose to play the levels in sequence or start from any level.
Currently, the game includes three unique levels, each increasing in difficulty and challenge.

* The player can choose to save the game progress, review it, or delete it and start a new.

*Everything runs entirely in the command line interface (CMD).

Use the arrow keys to move Mario, avoid obstacles (or smash them with a hammer (P)), and reach the top of each level to win!
